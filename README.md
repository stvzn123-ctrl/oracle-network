# 운명 네트워크 (Oracle Network)

이름, 생년월일, 출생 시각, 출생지를 넣으면 사주, 서양 점성술, 인도 점성술, 수비학, 마야력을
각 체계의 규칙대로 계산해 1~10년 뒤의 금전·애정·직업·건강 흐름을 종합합니다.
첫 화면은 결론과 핵심 세 가지만 보여 주고, 자세한 해석과 계산 근거는 8장짜리 운명 리포트에 담았습니다.

- 파일 하나(`index.html`)로 동작합니다. 브라우저로 열면 바로 실행됩니다.
- 입력값은 저장하지 않고 어디로도 전송하지 않습니다.
- 재미용입니다. 이 점술들이 미래를 맞힌다는 근거는 확인되지 않았습니다.

# 운명탐정 (Oracle Network)

이름, 생년월일, 출생 시각, 출생지를 넣으면 사주, 서양 점성술, 베딕점성술, 수비학, 마야력을
각 체계의 규칙대로 계산해 1~10년 뒤의 금전·애정·직업·건강 흐름을 종합합니다.
첫 화면은 결론과 핵심 세 가지만 보여 주고, 자세한 해석과 계산 근거는 10장짜리 운명 리포트에 담았습니다.

- 파일 하나(`index.html`)로 동작합니다. 브라우저로 열면 바로 실행됩니다.
- 로그인하지 않으면 입력값은 저장하지 않고 서버로 보내지 않습니다. 카카오 로그인 후 저장에 동의하면 출생 정보가 Cloudflare 서버(D1)에 저장되며, `저장 정보 삭제`나 카카오 연결 해제로 지울 수 있습니다.
- 유료 리포트의 온라인 결제는 아직 준비 중입니다. 열람은 관리자가 계정별로 승인합니다.
- 재미용입니다. 이 점술들이 미래를 맞힌다는 근거는 확인되지 않았습니다.

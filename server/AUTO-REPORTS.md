# 자동 리포트 연결

Worker 코드를 교체 배포하면 /reports는 권한 확인 후 저장된 profile로 리포트를 자동 조합합니다. private_reports의 수동 본문은 더 이상 읽지 않습니다. 권한이 없으면 403, 저장 프로필이 없으면 409를 반환합니다. 동일 프로필·기준연도·규칙 버전에서 동일 결과를 제공합니다. 관리자 미리보기 /admin/preview는 관리자 확인과 조회 기록을 남깁니다.

사이트는 리포트 클릭 시 /access 확인 → 승인됨: /reports 자동 생성, 미승인/비로그인: 목차·가격·결제안내 창. 결제하기는 현재 결제 준비 안내만 표시하며 실제 청구를 하지 않습니다. 관리자가 입금 확인 후 승인합니다.

배포: Cloudflare oracle-api Edit code에 worker.js 전체 교체 → Deploy. 기존 ADMIN_USER_IDS와 DB 바인딩은 유지합니다. DB 마이그레이션 추가 없음. 코드에는 기존 계산과 문구 조합이 포함되어 분량이 늘었습니다. 새 엔진은 복잡한 계산을 실행하므로 실제 Worker 사용량/CPU 제한을 확인해야 합니다.

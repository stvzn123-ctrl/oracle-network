# 관리자·수동 승인 배포

실제 결제는 연결하지 않습니다. 관리자가 결제 등을 확인한 뒤 수동으로 승인합니다.

1. 기존 Cloudflare Worker/D1에 access-migration.sql을 적용합니다. 기존 데이터는 지우지 않습니다.
2. 수정한 worker.js를 배포합니다.
3. 사이트에서 본인 카카오 로그인 후 내 정보에서 계정 ID를 확인합니다. /me는 본인의 id만 반환합니다.
4. Cloudflare Worker 비밀 변수 ADMIN_USER_IDS에 본인의 사용자 id를 등록합니다. 여러 계정은 쉼표로 구분합니다. 이름·생일은 관리자 인증에 사용하지 않습니다.
5. admin.html에서 사용자 목록 → 동의해 저장한 정보 확인 → 리포트 본문 등록 → 열람 승인 순서로 진행합니다. 전체 승인은 all입니다. 일부만 회수하려면 전체 승인을 먼저 회수해야 합니다.
6. 로그아웃 또는 비관리자 계정으로 관리자 API가 401/403인지 확인합니다. 미승인 리포트는 403, 승인됐지만 미등록은 404, 승인·등록된 본문만 반환합니다.

보안: 서버 세션으로 관리자 확인, 관리자 ID 비밀 변수, 본인에게 발급된 권한만 조회, 쓰기는 허용 Origin 확인, SQL 바인딩, 승인/회수/정보 조회 감사 기록, 보고서 일반 텍스트 렌더링. 공개 사이트에 배포된 과거 템플릿·계산 코드는 비밀 자료가 아니며 유료 본문은 private_reports에 별도 보관합니다.

이름 오은석/생일 1998-11-22를 아는 사람에게 권한을 주지 않습니다. 해당 프로필을 가진 실제 소유자 계정 ID를 운영자가 등록해야 합니다. 사이트 운영자 로그인·Cloudflare 배포 권한이 없는 실행 환경에서는 배포 및 관리자 지정 완료라고 주장하지 않습니다.
